# Ciphertext compatibility corpus — format v1

Generated by `scripts/generate-corpus.ts` on 2026-08-28, after the independent review
of Phase 2 changed the vault AAD and the record AAD (author binding). No user data
existed before that. From here on: **never regenerate or edit.** `test/corpus.test.ts` opens every blob here on every CI run; a future build
that cannot is a build that would lock real users out of their data.

- `users.json` — two users: passphrases, recovery codes, private keys (JWK, test
  keys only), public keys, safety numbers, passphrase vault and recovery vault.
- `drawer.json` — one drawer: raw drawer keys for key versions 1 and 2, wraps for
  both users under both versions, sealed entries (a hash chain of four ops incl.
  reverse and adjust), a sealed document, a sealed photo, and one entry re-sealed
  under key version 2.
- `archive.json` — an export archive with its password and plaintext.
- `passkey.json` — (added 2026-08-29, Phase 14, by `scripts/generate-corpus-passkey.ts`)
  the same two users' keys wrapped under a recorded 32-byte WebAuthn PRF output:
  the passkey vault. Same rule: never regenerate.

A new format version gets `corpus/v2/`; this directory stays forever.
